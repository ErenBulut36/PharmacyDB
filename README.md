# PharmacyDB — Eczane Yönetim Sistemi

İlaç stok takibi, reçete ve satış operasyonlarını yönetmek için C# ve Microsoft SQL Server kullanılarak geliştirilmiş masaüstü uygulaması.

## Öne Çıkan Özellikler
- İlaç stok kontrolü, reçete kaydı ve satış yönetimi için C# masaüstü arayüzü.
- Satış anında atomik stok düşümü, kritik stok görünümleri ve işlem kayıtlarının doğrudan SQL Server üzerinde **Stored Procedure**, **Trigger** ve **View** yapılarıyla yönetimi.

## Kullanılan Teknolojiler
C#, Microsoft SQL Server, T-SQL
